### Key Stories

- **F-Droid 2.0: A New Chapter for Android Freedom**
  After a year of work and 14 test releases, the official F-Droid app gets its largest update in a decade. The rewrite to Kotlin + Jetpack Compose simplifies navigation to Discover / Search / My Apps, expands categories (17 game genres alone), adds CJK-aware search over descriptions and translations, and turns on automatic background updates by default. The installer story is the real news: thanks to EU DMA pressure, Android now offers third-party stores a pre-approval API, so F-Droid installs confirm up-front instead of after download — nearly parity with the Play Store. The F-Droid Privileged Extension is dropped; panic features survive, but the Ripple-triggered app wipe is gone for now. HN's thread (1,265 points) split between applause and grumbling about Material-ized minimalism.
  Sources: https://f-droid.org/2026/09/24/f-droid-2.0-a-new-chapter-for-android-freedom.html · https://news.ycombinator.com/item?id=49831968

- **Google's Project Suncatcher puts TPUs in orbit next week**
  Google's space-compute moonshot moves from paper to hardware: a prototype satellite carrying Trillium TPUs launches on SpaceX's Transporter-18 rideshare (built with Planet). The blog post details the engineering: components see 50–100 g at launch, Trillium survived a proton-beam dose exceeding a five-year mission's radiation at UC Davis's Crocker lab, and cooling in vacuum requires heat pipes plus radiators rather than airflow. The 2027 milestone is a two-satellite laser-interconnect test — the hard part is high bandwidth over short distances between moving satellites. The pitch: low Earth orbit gets ~8x more solar power than the ground.
  Sources: https://blog.google/innovation-and-ai/models-and-research/google-research/google-project-suncatcher-facts/ · https://news.ycombinator.com/item?id=49830606

- **Gemini 3.8 Live with Live Avatar: real-time video personas for enterprise agents**
  One week after Gemini 3.8 Live, Google adds Live Avatar — streaming video generation coupled to the live dialogue model, with precise lip-sync, natural expressions, and asynchronous tool calling so the avatar keeps talking while backend tools run. It switches across 97 languages without visual drift, supports custom avatars from a reference image (enterprise allowlist), and watermarks everything with SynthID. Available now in Gemini Enterprise. The pattern to watch: voice-first agents are quietly becoming video-first.
  Source: https://blog.google/innovation-and-ai/models-and-research/gemini-models/gemini-3-8-live-with-live-avatar/

- **"Two-tier encryption" in the UK, one year on**
  A sharp field-notes piece reconstructs the Apple–UK Advanced Data Protection standoff and where it landed: the UK's secret Technical Capability Notice (January 2025, global scope) was narrowed to UK-only after US pressure in late 2025; Apple pulled ADP for new UK users rather than build a backdoor; existing users keep it because Apple's servers can't roll back the setting. Result: two UK residents with identical iPhones have different encryption. This month, Wyden and Davidson pressed the Investigatory Powers Tribunal to open proceedings, and Apple asked the tribunal to lift the gag so "facts can be deployed in the open." The secrecy — not the crypto — is the story.
  Sources: https://macanorak.com/two-tier-encryption-in-the-uk/ · https://news.ycombinator.com/item?id=49828731

- **Claude Code changelog (Sep 24): telemetry transparency and a pile of thinking-block fixes**
  Yesterday's Claude Code release adds a `maxProseWidth` setting, a startup notice plus `/status` and `claude doctor` entries that name telemetry variables in project settings that were ignored or disabled telemetry, and a managed setting letting `claude --chrome` coexist with an exclusive managed-MCP config. Under the hood: a long list of fixes for resumed/continued sessions silently re-sending altered history and dropping extended thinking — the kind of bug that quietly corrupts agent context. Auto mode now uses the server-side permission classifier by default on direct API connections when telemetry is off.
  Source: https://code.claude.com/docs/en/changelog

- **Show HN: Bastardica — cursed font mashups in the browser**
  A Pyodide + fontTools web app that mixes any two fonts ("Times New Roman but every 5th glyph is Papyrus"), with Y-offset/scale effects and ligature-based contextual substitution so the result works anywhere OpenType is shaped. Entirely client-side; exports normal OpenType files. 716 HN points of pure joy — the thread is full of Helvetica/Arial pranks and a designer mixing Papyrus into Comic Sans.
  Sources: https://bastardica.mitpit.com · https://news.ycombinator.com/item?id=49823738

- **Show HN: Whiteboard (YC W26) — an open-source canvas where agents diagram their work**
  A desktop app (vendored Code-OSS fork, MIT) that plugs into Claude Code / Codex and gives the agent an SDK to draw sequence diagrams, ERDs, and trace quotes on a canvas — each element click-throughs to the underlying code. Ships an AST-aware semantic diff viewer in Rust that collapses tests/docs and summarizes large added functions as pseudocode. The bet: in agent-driven development, the bottleneck is reviewing and understanding, not writing.
  Sources: https://github.com/devdotfast/whiteboard · https://news.ycombinator.com/item?id=49833867
