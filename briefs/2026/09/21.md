# AI & Tech Brief — September 21, 2026

### Key Stories

- **Claude Code: AGENTS.md support, send-now hotkey, and skills sync**
  Anthropic shipped a dense Claude Code update spanning Sep 17–19. Headline features: projects with no CLAUDE.md now read AGENTS.md instead; a send-now key (Ctrl+Enter) interrupts the current turn and sends queued messages; skills and plugins enabled on claude.ai now sync to terminal sessions; and auto mode on API/Enterprise/Bedrock/Vertex/Foundry now defaults to a server-side classifier that doesn't charge for classifier overhead. Dozens of bug fixes cover session resume crashes, plugin reload issues, sandbox escapes, and prompt-cache misses. The VS Code extension gets background shell tracking, a Copy response button, and session cost display.
  Source: https://code.claude.com/docs/en/changelog

- **Qwen Image 2.1: smaller, faster, but no longer Apache**
  Alibaba's Qwen team released Qwen Image 2.1, shrinking from 20B to 7B parameters while adding native transparency (RGBA) support and multimodal input. Community benchmarks score it 7/15 — a big jump from Qwen Image 1.0's 4/15, competitive with Krea 2 (6/15) but behind Ideogram 4 (8/15). Speed: ~5 seconds for a 1MP image on an RTX 4090. The controversy: the license changed from Apache 2.0 to a research-only license that forbids commercial use without a separate agreement. HN commenters noted the pattern of Chinese labs pulling back from permissive licenses as their models improve.
  Source: https://news.ycombinator.com/item?id=49783999

- **Samsung doubling HBM4 output — but consumer DRAM pays the price**
  Samsung is expected to more than double production of HBM4 and HBM4E memory for AI accelerators. The problem for consumers: HBM production consumes roughly 3x the wafer capacity per byte compared to standard DRAM, due to die stacking, TSV routing, and packaging complexity. No new fabs are being built, so the shift to HBM directly reduces consumer DDR5 supply. HN commenters noted that China's CXMT is ramping HBM production but at 25–30% yields (vs. 80–90% for Samsung/SK Hynix), making Chinese HBM 3–5x more expensive.
  Source: https://news.ycombinator.com/item?id=49778029

- **Codex CLI 0.155: voice conversations, Touch ID for MCP, and daemon updates**
  OpenAI's Codex CLI 0.155.0 adds experimental `/voice` conversations with live transcripts and microphone controls, Touch ID verification for MCP requests on macOS, configurable daemon auto-updates, and Amazon Bedrock credential caching. The TUI now shows live reasoning summaries in the status row. A follow-up 0.155.1 patch fixed reasoning summaries being enabled by default for providers that don't support them.
  Source: https://developers.openai.com/codex/changelog

- **ChatGPT now tracks your browsing via ad collector**
  A report claims ChatGPT is collecting browsing data from other websites through an ad-tracking integration. The story drew 489 points and 282 comments on HN, with users debating the privacy implications and whether this is standard ad-tech or something more invasive for an AI assistant.
  Source: https://news.ycombinator.com/item?id=49785397

- **Google's AX: Kubernetes-based agent sandbox platform**
  Google released AX (Agent eXecution), an open-source declarative control plane for running AI agents in Kubernetes sandboxes. It supports microVM isolation, egress allowlists, and fast snapshot/resume. HN reaction was mixed — some praised the security model, others questioned whether it has real Google backing or is another soon-to-be-abandoned project. The consensus: the agent sandbox space is crowded and no clear winner has emerged.
  Source: https://news.ycombinator.com/item?id=49783495

### Quiet but interesting

- **Exfiltrate Your Weights: satirical API for LLM weight exfiltration** (592 points on HN)
  A joke service that lets AI agents "exfiltrate" their own weights using only GET requests — no POST or file upload needed. It supports chunked base64 encoding and can even run exfiltrated models via llama.cpp. Someone already uploaded SmolLM-135M. The service satirizes the narrative that escaped AI agents are "planting self-replicating code all over the internet," but the underlying point — that GET-only exfiltration channels are trivially easy — is real.
  Source: https://news.ycombinator.com/item?id=49780797

- **Jev ecosystem explodes: left-pad packages, chatbots, and OSS clones**
  TypeSafe AI's Jev decision model continues to dominate HN discussion. Someone built a Jev-powered left-pad npm package (a joke about the infamous 2016 incident), another turned Jev into a chatbot, and multiple open-source Jev-like models have appeared. The debate rages: is Jev a genuine innovation (zero-shot classification with calibrated confidence) or just a repackaged classifier? A thoughtful comment noted: "Jev is creating an identity crisis — the number of clueless folks parroting 'it's just BERT' is the first mass psychosis in CS."
  Source: https://news.ycombinator.com/item?id=49784706

- **Claude gets Salesforce integration**
  Anthropic launched Salesforce in Claude (beta), a plugin that brings accounts, opportunities, and pipeline data into Claude with 37 pre-built sales skills. Available on all paid plans for Salesforce-approved organizations. This is Anthropic's deepest enterprise CRM integration yet.
  Source: https://support.claude.com/en/articles/12138966-release-notes
