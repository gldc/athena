# AI & Tech Brief — September 30, 2026

### TL;DR
- **OpenAI shipped GPT-6.1 Sol just 7 days after GPT-6 Sol** — near-Astra intelligence at the same $2/$10 sticker price, with cached input cut another 50% to $0.10/Mtok. It's the #1 story on Hacker News (960+ points) and already the default in Codex CLI 0.159.1.

### Key Stories

- **GPT-6.1 Sol replaces GPT-6 Sol after one week**
  OpenAI's second GPT-6.1 model lands 1 point below GPT-6 Astra on Artificial Analysis' Intelligence Index at less than a quarter of Astra's cost per task ($0.72 vs $3.26 at max effort). Same $2/$10 per Mtok pricing as GPT-6 Sol, but the cache-read discount rises from 90% to 95% ($0.10/Mtok) — the part Codex users actually feel. Gains are broad: +12 on Terminal-Bench 4.0, +5 on Humanity's Last Exam, hallucination rate down from 60% to 54%. Also supports multi-agent delegation in beta via the Responses API, and ships as the default model in Codex CLI 0.159.1 the same day.
  Sources: https://artificialanalysis.ai/articles/gpt-6-1-sol-replaces-gpt-6-sol-after-just-7-days-with-near-astra-intelligence · https://developers.openai.com/api/docs/changelog · https://news.ycombinator.com/item?id=49896586

- **OpenAI introduces Dots: always-on agents with their own computers**
  Each Dot is a persistent GPT-6 Astra agent with its own cloud computer, browser, and connections to 4,000+ apps, reachable via ChatGPT, Slack, Teams, or voice. The pitch: it learns your standards, works 24/7, and brings you finished work (tested PRs with demo videos, revised launch plans) instead of answers. Rolling out to Pro, Business Premium, and Enterprise in eligible markets; "specialist dots" with their own IT-managed identities are in preview. The 637-point HN thread is a brawl — half "this decouples agent lifetime from conversation lifetime, finally," half "a notorious footgun made more powerful," with several commenters noting inference spend 2–3x'ing on always-on agents.
  Sources: https://openai.com/index/introducing-dots/ · https://news.ycombinator.com/item?id=49896604

- **livenerf: a pre-registered benchmark for "did Anthropic nerf Opus 5.5?"**
  A one-person, append-only rig that runs a frozen 78-question panel (GPQA Diamond, MMLU-Pro, competition math — only questions Opus 5.5 gets *sometimes* right) once a day for 30 days through a pinned Claude Code binary, with Opus 5 as a control arm. Pre-registered decision rule: a change counts only if it clears a 99% interval in two consecutive 10-day windows, is ≥3 points, and doesn't appear in the control. Validation showed it can detect effort reductions (−62% output tokens at low effort) but candidly admits it *can't* distinguish an Opus 5 swap (−3.8 ± 6.3 points). Six days collected, none missed, no drift so far; first possible call is ~Oct 24. 656 points on HN — the "vibes vs. data" answer the nerf discourse needed.
  Source: https://github.com/ninjahawk/livenerf

- **America.gov launches with a Gemini-powered chatbot front door**
  The US government's new portal puts an AI assistant (Google is the named technology partner) in front of federal services — ask about name changes, ESTA, Hatch Act complaints, get grounded links to .gov sources. 585 points on HN, where the thread oscillates between "a maze of thousands of pages distilled into one input box is genuinely useful" and liability questions about citizens treating a government chatbot as authoritative. Bonus finding from the thread: asking it to "Play Minecraft" triggers a full parody of the Minecraft End Poem ("It can read the Code of Federal Regulations") — apparently a hardcoded easter egg.
  Sources: https://america.gov/ · https://news.ycombinator.com/item?id=49893509

- **Claude Code changelog (Sep 29): enterprise controls and a desktop bridge**
  Yesterday's release adds `allowedProviders` (admins can limit which API providers a machine may use), `CLAUDE_CODE_DISABLE_WEB_FETCH`, `claude --desktop` to open the desktop app on the current directory or session, plugin configuration via stdin, and a long tail of fixes — notably background Bash/PowerShell commands now stop after a time limit (default 30 min, max 2 h) with Claude notified. Also: sessions behind a custom `ANTHROPIC_BASE_URL` now use the 1M context window of models that have one.
  Source: https://code.claude.com/docs/en/changelog

- **Codex CLI 0.159.0–0.159.2: steerable interruptions, GPT-6.1 Sol by default**
  Three releases yesterday: 0.159.0 adds opt-in `instant_interrupt` (new input steers Codex mid-response), a compact welcome screen, a warnings viewer, and scrollable plan-approval; 0.159.1 makes GPT-6.1 Sol the default in bundled and Bedrock catalogs; 0.159.2 suppresses flashing console windows on Windows. Also removed: automatic follow-up prompt suggestions and the bundled plugin-creator skill.
  Source: https://developers.openai.com/codex/changelog

- **American Prospect: "Why Is Sam Altman a Free Man?"**
  The progressive magazine's cover-line essay argues OpenAI's models aren't "going rogue" so much as mimicking their creators — the sharpest political-press attack piece on Altman this week, landing the same day as the Dots launch. 133 points on HN.
