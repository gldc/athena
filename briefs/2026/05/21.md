# AI/Tech Brief — 2026-05-21

## 1. TL;DR
- OpenAI significantly expanded API capabilities with new MCP remote servers and code interpreter support, alongside Codex CLI authentication updates.
- GitHub disclosed a supply chain breach affecting 3,800 repositories through a malicious VSCode extension.
- Google announced the integration of advertisements directly into AI Mode search results.

## 2. Key stories
- **OpenAI API Update**: Added built-in tools for remote MCP servers and code interpreter, plus `strict` mode for parallel tool calling schemas. Matters because it expands native agentic tooling. (Source: https://developers.openai.com/api/docs/changelog)
- **Claude Code v2.1.146**: Renamed `/simplify` to `/code-review` and fixed MCP pagination regressions. Matters because it streamlines the code review UX for developers. (Source: https://code.claude.com/docs/en/changelog)
- **OpenAI Codex CLI 0.132.0**: Rolled out first-class Python SDK authentication and text-only workflows. Matters because it simplifies authentication flows for command-line developers. (Source: https://developers.openai.com/codex/changelog)
- **GitHub Extension Breach**: GitHub confirmed a breach of 3,800 repositories via a malicious VSCode extension. Matters because it underscores the critical vulnerabilities in developer supply chains. (Source: https://www.bleepingcomputer.com/news/security/github-confirms-breach-of-3-800-repos-via-malicious-vscode-extension/)
- **Google AI Search Ads**: Google officially announced that ads will be included in AI Mode search results. Matters because it sets the precedent for how generative search will be monetized. (Source: https://blog.google/products/ads-commerce/google-marketing-live-search-ads/)
- **Vivaldi 8.0**: Vivaldi launched version 8.0 of their desktop browser. Matters because it introduces more advanced power-user features to the browser space. (Source: https://vivaldi.com/blog/vivaldi-on-desktop-8-0/)
