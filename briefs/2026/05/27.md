# AI & Tech Brief — May 27, 2026

## TL;DR
- OpenAI rolled out Workload Identity Federation for API and major Codex CLI updates including thread search and MCP setup improvements.
- Claude Code 2.1.152 introduced auto-applied code reviews, skill re-scanning, and auto mode without opt-in consent.
- Hacker News front page features the launch of Cloudflare Flagship, the retirement of Dropbox's CEO, and a critical Starlette Host-Header auth bypass vulnerability.

## Key Stories

**Claude Code 2.1.152 Released**  
The new version features `/code-review --fix` to apply findings directly to the working tree, and auto mode now requires no opt-in. Additionally, skills can set disallowed-tools in frontmatter.  
[Source](https://code.claude.com/docs/en/changelog)

**OpenAI API Supports Workload Identity Federation**  
Trusted workloads can now exchange externally issued identity tokens for short-lived OpenAI access tokens, eliminating the need to store long-lived API keys.  
[Source](https://developers.openai.com/api/docs/changelog)

**OpenAI Codex CLI 0.134.0**  
Added local conversation thread search and enhanced Model Context Protocol (MCP) support with per-server environment targeting and OAuth options. Read-only tools can now run concurrently.  
[Source](https://developers.openai.com/codex/changelog)

**Cloudflare Flagship Launches**  
A major new product announcement from Cloudflare hit the top of Hacker News today, signaling a significant strategic addition.  
[Source](https://developers.cloudflare.com/flagship/)

**Dropbox CEO Drew Houston to Step Down**  
After a long tenure, Drew Houston is stepping down as CEO of Dropbox, marking the end of an era for the cloud storage pioneer.  
[Source](https://www.cnbc.com/2026/05/26/dropbox-ceo-drew-houston-ashraf-alkarmi.html)

**BadHost (CVE-2026-48710) Disclosed**  
A new vulnerability, Starlette Host-Header Auth Bypass, was published, potentially affecting Python web apps using the popular ASGI framework.  
[Source](https://badhost.org/)

**Raft Consensus with a Minority of Nodes**  
A new systems design paper discusses the conditions under which Raft consensus can be maintained with only a minority of nodes, sparking architectural debate.  
[Source](https://padhye.org/raft-minority/)
