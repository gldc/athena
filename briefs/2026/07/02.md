# AI/Tech Brief — 2026-07-02

## TL;DR
- **Claude in Chrome & Background Agents:** Claude Code 2.1.198 introduces GA for Claude in Chrome and background agents that can auto-PR.
- **Enterprise Controls for Claude:** Anthropic restored access to Claude Fable 5 and Mythos 5, and added enterprise model entitlements.

## Key Stories

- **Claude Code v2.1.198 Released**
  Claude in Chrome is now generally available. Background agents have been added with notifications, allowing them to auto-commit and open draft PRs upon completion.
  *Source: [Claude Code Changelog](https://code.claude.com/docs/en/changelog)*

- **Anthropic Restores Models and Adds Enterprise Controls**
  Access to Claude Fable 5 and Mythos 5 has been restored, and new Enterprise controls allow admins to manage model entitlements and effort levels.

- **Kimi K2.7 Code GA in GitHub Copilot**
