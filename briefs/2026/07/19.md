# AI/Tech Brief — 2026-07-19

## 1. TL;DR
- Claude Code received major updates adding a new EndConversation tool, manual skill invocation, and improved logging.
- OpenAI has refreshed its bundled instructions for Codex and corrected the model context size down to 272k tokens.
- Qwen3.8 is launching and going open-weight soon, with a max preview currently available.

## 2. Key stories
- **Claude Code v2.1.214 and v2.1.215**: Major updates brought stability to remote sessions, OpenTelemetry logging, and a new EndConversation tool to handle abusive users. Skills like /verify and /code-review must now be invoked manually. (https://code.claude.com/docs/en/changelog)
- **Codex CLI 0.144.6 Update**: OpenAI refreshed the bundled instructions for the GPT-5.6 model family (Sol, Terra, and Luna) and reduced the Codex model context size from 372k to 272k. (https://developers.openai.com/codex/changelog) (https://github.com/openai/codex/pull/33972/files)
- **Qwen3.8 Launching Soon**: Qwen announced that version 3.8 is launching and will be going open-weight, alongside the release of the Qwen 3.8 Max Preview. (https://twitter.com/Alibaba_Qwen/status/2078759124914098291) (https://www.qwencloud.com/pricing/token-plan)
- **Claude Code is now using Bun written in Rust**: A significant runtime shift aimed at boosting performance and efficiency. (https://simonwillison.net/2026/Jul/19/claude-code-in-bun-in-rust/)
- **Superhuman AI highlights Robotics**: In a new robotics special, Superhuman AI claims that America's next big car is a robot. (https://www.superhuman.ai/)
