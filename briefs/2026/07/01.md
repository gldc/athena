# AI/Tech Brief — 2026-07-01

**TL;DR**
- **Claude Sonnet 5** launched with a native 1M-token context window and massive reasoning improvements, becoming the default model in Claude Code.
- **Anthropic's Claude Fable 5 & Mythos 5** had their US export controls lifted, while a new product named **Claude Science** was introduced.
- **Meta** successfully demonstrated turning brain waves directly into text without surgery.

### Key Stories

- **Claude Sonnet 5 Launch & Claude Code Integration**: Anthropic released Claude Sonnet 5, dubbed their most "agentic" model yet with a massive 1M-token context window. It has immediately been rolled out as the default model within the Claude Code CLI, driving stronger reasoning and coding capabilities. [Source](https://support.claude.com/en/articles/12138966-release-notes) | [Claude Code](https://code.claude.com/docs/en/changelog)
- **Export Controls Lifted for Claude Fable 5 and Mythos 5**: The US Department of Commerce has officially lifted export restrictions on two of Anthropic's new models, significantly expanding their global availability. [Source](https://twitter.com/AnthropicAI/status/2072106151890809341)
- **Godot Rejects AI-Authored Code**: The widely used open-source Godot game engine announced it will no longer accept AI-authored code contributions. Maintainers cited growing distrust in heavy AI users' ability to fully understand and fix their own submitted code. [Source](https://www.pcgamer.com/gaming-industry/open-source-game-engine-godot-will-no-longer-accept-ai-authored-code-contributions-we-cant-trust-heavy-users-of-ai-to-understand-their-code-enough-to-fix-it/)
- **Meta's Brain-to-Text Research Breakthrough**: Meta has unveiled a novel path to human-AI communication, successfully turning brain waves into words without the need for invasive surgery. [Source](https://ai.meta.com/blog/brain2qwerty-brain-ai-human-communication/?_fb_noscript=1)
- **Claude Science**: Anthropic launched a dedicated product for the scientific research community dubbed "Claude Science", likely aiming to accelerate AI-driven research. [Source](https://claude.com/product/claude-science)
- **DeepMind's Nano Banana 2 Lite & Gemini 3.5 Flash**: Google DeepMind continues a rapid cadence with the release of Nano Banana 2 Lite for device-level models, building on the recent introduction of computer use in Gemini 3.5 Flash. [Source](https://deepmind.google/models/gemini-image/flash-lite/)
- **Mistral's Leanstral 1.5**: Mistral released the Leanstral 1.5 model, providing another lightweight yet powerful open-weight option for developers. [Source](https://docs.mistral.ai/models/model-cards/leanstral-1-5-26-06)
- **Claude Code Steganography**: Reports suggest that Claude Code is steganographically marking its output requests, raising interesting questions about prompt watermarking and tracking. [Source](https://thereallo.dev/blog/claude-code-prompt-steganography)

### Quiet but interesting

- **Kubernetes Ported to the Browser**: An engineer successfully ported Kubernetes to run entirely in a web browser. [Source](https://ngrok.com/blog/i-ported-kubernetes-to-the-browser)
- **CERN LHC Long Shutdown 3**: CERN officially bids farewell to the Large Hadron Collider as it enters its planned "Long Shutdown 3" phase for major upgrades. [Source](https://home.cern/cern-bids-farewell-to-the-lhc-and-enters-long-shutdown-3/)
