# AI/Tech Brief — 2026-07-24

### TL;DR
- **Claude Code and OpenAI API get safer:** Claude Code now runs code reviews in the background and improves safety adjudication, while OpenAI API introduces hard spend limits to prevent bill shock.
- **New AI Models hit the scene:** DeepMind unveiled computer use capabilities for Gemini 3.5 Flash, and Black Forest Labs launched Flux 3 to significant community interest.
- **Claude Cowork updates:** Superhuman AI highlights new screen memorization skills for Claude Cowork.

---

### Key Stories

**Claude Code 2.1.218 improves background tasks and safety**  
The `/code-review` command now runs as a background subagent to avoid cluttering active conversations, and Auto Mode adjudication for potentially dangerous commands (like `rm`) has been enhanced to reduce unnecessary permission dialogs.  
[Source](https://code.claude.com/docs/en/changelog)

**OpenAI introduces API hard spend limits**  
Developers can now set monthly hard spend caps at both the organization and project levels. Requests will return a 429 error once the limit is reached, giving teams better control over costs.  
[Source](https://developers.openai.com/api/docs/changelog)

**DeepMind introduces computer use for Gemini 3.5 Flash**  
Google has expanded the capabilities of the Gemini Flash family, announcing new computer use features for Gemini 3.5 Flash to enable more agentic workflows.  
[Source](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)

**Black Forest Labs releases Flux 3**  
Flux 3 and Flux 3 Mimic have officially launched, quickly rising to the top of Hacker News discussions as the community evaluates the new generation of open-weight models.  
[Source](https://bfl.ai/blog/flux-3)

**Claude Cowork gains screen memorization skills**  
Superhuman AI's daily newsletter highlighted that Claude Cowork has received updates allowing it to utilize screen memorization for better contextual awareness.  
*Source: Superhuman AI newsletter*

### Quiet but Interesting

**Gemini CLI v0.52.0 improves tool reliability**  
The latest release bypasses LLM correction for JSON and IPYNB files in `write_file` and `replace` tools, significantly improving reliability for these file types.  
[Source](https://geminicli.com/docs/changelogs/)

**Claude Cookbook launched**  
A new cookbook resource has been published, offering developers practical examples and guides for building applications with Claude.  
[Source](https://platform.claude.com/cookbook/)
