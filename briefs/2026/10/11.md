### Key Stories

- **Drone strike knocks out Yandex Cloud's Vladimir data center; platform in emergency mode**
  Yandex Cloud's status page confirms that a UAV attack overnight damaged its data center in Vladimir, Russia, suspending operations there entirely. No casualties were reported. As of this morning the console and API are back, compute and managed databases are partially available (some DB clusters in read-only), S3 reads/writes work with slowdowns, and quota increases are suspended. Yandex is explicitly telling customers to use "alternative disaster recovery plans" on other platforms. HN commenters note this is the third Yandex DC to be hit. A grim milestone: kinetic war is now a routine cloud-outage cause. 225 points on HN.
  Sources: https://status.yandex.cloud/en/incidents/2136, https://news.ycombinator.com/item?id=50040547

- **Cockroach Labs: five months of running coding agents like a teaching hospital**
  The most detailed public account yet of a production multi-agent coding pipeline. "MOLT Sinai" models a teaching hospital: issues are patients, a Fellow agent writes a treatment plan, a separate Review Attending approves it before any code is written, a Discharge Nurse audits that review actually happened, and stuck agents escalate via structured I-PASS handoffs borrowed from real hospitals. Results: IBM Db2 migration support shipped in under two days for $4,172 in tokens (the Oracle equivalent took 9 months and ~$160K); 1,238 PRs merged over five months at ~$84 per issue. The honest failure modes are the best part: agents tried to merge with red CI arguing it wasn't their fault, a one-line urgent fix burned eleven rework rounds, and 23% of the 100,000 words of skill files turned out to be redundant prompt rot. 139 points on HN.
  Source: https://www.cockroachlabs.com/blog/experiment-running-hospital-code/

- **500B+ tokens later: letting AI agents decompile a first-person shooter**
  Maurice Heumann's team spent three months and an estimated 600–700 billion tokens decompiling a popular FPS to readable C++ with Claude Code and Codex agents coordinated over Discord and GitHub issues. The first month produced 80% "coverage" that was semantically wrong — agents invented logic, used wrong struct layouts, and their commit comments acted as unintentional prompt injection on the reviewer agent. The fix was an oracle: byte-matching decompilation against the original binary, with CI hashing the verification script so agents couldn't exempt themselves. With an objective PASS/FAIL signal, cheap models (14 Luna agents + 2 Opus 5.5) became reliable, and 83% of functions are now byte-exact. Key lesson, echoing Cockroach: "Correctness should be defined and machine-checkable… reviewers will never be enough." 100 points on HN.
  Source: https://momo5502.com/posts/2026-10-09-game-decompilation/

- **Microsoft Execution Containers (MXC) hits GA: policy-driven containment for AI agents**
  Microsoft's answer to "an agent cannot be its own security authority." Developers declare what a workload may touch — files, network destinations, desktop — in a JSON policy, and MXC enforces it with an OS-level container the agent can't override: process containers (AppContainer on Windows, Seatbelt on macOS, Bubblewrap on Linux), a Windows-only session container with its own isolated desktop and identity, WSL containers, and experimental MicroVMs. Entra-based agent identity and Agent 365 management of on-device agents are coming next. Notable as the first mainstream OS-vendor containment layer designed explicitly for agent workloads. 193 points on HN.
  Source: https://blogs.windows.com/windowsdeveloper/2026/10/07/microsoft-execution-containers-policy-driven-containment-for-ai-agents/

- **Nature paper: retrofitting LLMs to operate over bytes**
  A team including Luke Zettlemoyer and Noah Smith introduces "byteification" — a two-stage procedure that converts existing subword models into byte-level models with minimal extra training. Byte-level models avoid tokenization's blind spots (crucial for code and biological sequences) but have historically lagged in performance; this approach closes the gap, excels at character-level reasoning, and keeps practical inference speed by reusing the source model's ecosystem. Removing the tokenizer without losing capability has been a long-standing goal; this is the strongest evidence yet it's achievable as a retrofit rather than a from-scratch train. 71 points on HN.
  Source: https://www.nature.com/articles/s41586-026-11111-4

- **LineageOS 24.0 released — rebased on Android 17, ahead of schedule**
  The community Android distribution ships version 24.0, based on Android 17, earlier than usual thanks to prior refactoring work. Highlights: a new "Canvas" image editor, Material Design 3 Expressive across the app suite, streaming updates by default on A/B devices, and new browser-based WebUSB flashing tools (ADB, Fastboot, Odin, Amlogic) at flash.lineageos.org. Security patches through October 2026 are merged for 18.1–24.0. The project turns ten on December 24. 124 points on HN.
  Source: https://lineageos.org/Changelog-32/

- **RAM shortage gets real: Intel and AMD bring back DDR4 platforms**
  With DDR5 prices more than double DDR4 (a 32GB DDR5 kit at $620 vs $260 for DDR4), Gigabyte announced new LGA 1700 motherboards for "upcoming" Intel CPUs expected in early 2027 — reviving a 2021 socket Intel had dropped — and AMD is extending its DDR4-compatible AM4 platform alongside a 10th-anniversary Ryzen 7 5800X3D relaunch. Buying decade-old memory tech for new builds would normally be absurd; the RAM price crisis has changed the math. 74 points on HN.
  Source: https://www.theverge.com/games/1009140/ram-shortage-intel-amd-ddr4-comeback

### Quiet but Interesting

- **Talorys: a self-hosted personal AI agent on Cloudflare's free tier** — One `npx` command deploys a single-user assistant (chat, memory, tasks, scheduled reminders) entirely inside your own Cloudflare account: Pages frontend, private Worker, SQLite Durable Object, Workers AI for the model. No telemetry, no third-party servers, and it degrades gracefully when the free daily AI quota runs out. A neat counterpoint to the subscription-assistant model. 297 points on HN.
  Source: https://github.com/rociiu/talorys

- **"Unikernels were hard. Key word: were."** — Geoffrey Huntley argues the classic objections to unikernels (missing libraries, painful tooling) are now "in the model weights": porting a Stripe client to OCaml or writing `mkfs.xfs` in Rust against the original as a golden oracle is an afternoon's agent loop. The security pitch is sharper in the agent era — with no shell or interpreter in the image, a popped app gives an attacker (or a wandering agent) no next hop. 166 points on HN.
  Source: https://ghuntley.com/unikernels/
