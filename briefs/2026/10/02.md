# AI & Tech Brief — October 2, 2026

### TL;DR
- **Pi 1.0 shipped** — the minimal agent harness from Earendil hit its first stable release, adding Codemode (native MCP + non-LLM model support), deferred tool loading, and cache warming. Alongside it, the experimental **Pi Durable** framework launched for building long-running, crash-surviving agents. #1 on Hacker News with 1,300+ points.

### Key Stories

- **Pi 1.0: minimal agent harness goes stable**
  Earendil shipped Pi 1.0, a hardened, minimal, extensible agent harness. New in 1.0: Codemode (native MCP support and non-LLM models like Jev and image models), extension support for virtual models, deferred tool loading, cache warming for Anthropic models, mid-conversation system messages, a new TUI theme, and full-screen mode by default. Pi runs the latest models from every major provider and is MIT licensed. 1,336 points on HN.
  Sources: https://earendil.com/posts/pi-1-0/ · https://news.ycombinator.com/item?id=49926069

- **Pi Durable: experimental framework for long-running agents**
  Alongside Pi 1.0, Earendil shipped Pi Durable — an experimental TypeScript framework for building durable, crash-surviving agentic applications. Key properties: every step checkpoints to storage (SQLite, JSONL, or in-memory), so a killed process resumes from its last checkpoint; conversations fork without copying history; tools declare whether they're safe to rerun after a crash; and multiple clients can attach to and steer the same conversation. The entire source is ~15K lines (~150K tokens), small enough for an agent to read. Available as `@earendil-works/pi-durable` on npm. 395 points on HN.
  Sources: https://earendil.com/posts/pi-durable/ · https://news.ycombinator.com/item?id=49925969

- **Cloudflare Clef: open-weight decision models + RL fine-tuning**
  Cloudflare released Clef and Clef-flash, decision models trained on Qwen backbones that produce bounded structured outputs (not free-form text) for agentic workflows. Clef has a vision encoder and 64K context (vs Jev's 32K). On the Jev Decision Index, Clef leads on most benchmarks; Clef-flash is significantly faster (38.8ms median vs Jev's 524ms). Both are Apache 2.0 on Hugging Face, hosted on Workers AI. Cloudflare also debuted an RL fine-tuning service — first hands-on with their FDE team, later self-serve — using AI Gateway for data capture, Containers for RL sandboxes, and Workers AI for redeployment. 525 points on HN.
  Sources: https://blog.cloudflare.com/clef-decision-models/ · https://news.ycombinator.com/item?id=49923692

- **DeepSeek Harness: open-source desktop agent in public preview**
  DeepSeek launched Harness, a desktop app for macOS and Windows built on a plugin architecture ("everything is a plugin"). It covers everyday work (docs, data, slides), coding, research, and background tasks. Plugins can be installed or created through chat in "Creator mode." The web UI launches with `npx @deepseek-ai/dsh web`; full source is on GitHub. 252 points on HN.
  Sources: https://www.deepseek.com/en/harness/ · https://news.ycombinator.com/item?id=49929489

- **SvelteKit 3 released**
  SvelteKit 3.0 is out. Breaking changes: config moves to `vite.config.ts`, `$lib` becomes `#lib` (standard subpath imports), environment variables are more powerful, service workers are less boilerplatey, and error handling is improved. Migrate with `npx sv migrate sveltekit-3 --tasks all --confirm`. Remote functions (type-safe client-server communication) are the top priority but not ready yet — they require Async Svelte behind an experimental flag. 288 points on HN.
  Sources: https://svelte.dev/blog/sveltekit-3-is-here · https://news.ycombinator.com/item?id=49926536

- **Linux kernel: massive security update**
  Debian released DSA-6528-1, patching hundreds of CVEs in the Linux kernel — privilege escalation, denial of service, and information leaks. Fixed in version 6.12.111-1 for the stable distribution (trixie). If you run Debian stable, upgrade your linux packages. 328 points on HN.
  Sources: https://lwn.net/Articles/1097401/ · https://news.ycombinator.com/item?id=49928121

- **Claude Code changelog (Oct 1): Claude Mods, You should know, and a long tail of fixes**
  Yesterday's release added Claude Mods (plugins that modify deeper behavior), a built-in "You should know" mod where a side agent watches for things you or Claude might miss, an `n:<text>` filter for the agents view, URL prompts from MCP servers on the 2025-11-25 protocol, and a built-in `gh api` for self-hosted runners without GitHub CLI. Also: Opus 4.7+ and Fable now default to 1M context on Bedrock/Vertex/Foundry/gateway. Dozens of fixes across Windows, macOS, screen reader mode, and cloud sessions.
  Source: https://code.claude.com/docs/en/changelog

- **OpenAI API changelog (Sep 29–Oct 1): computer use in Agents API, GPT-6.1 Sol**
  OpenAI added computer use to the Agents API (Sep 29) — agents can complete tasks in an OpenAI-hosted browser with website access approvals and sign-in handled by your application. Also released GPT-6.1 Sol (`gpt-6.1-sol`) for complex coding and professional work at lower cost than GPT-6 Astra ($2/$10 per Mtok standard), with Multi-agent support in beta. GPT-6 Astra got an Ultrafast mode (`service_tier: "ultrafast"`) for reduced inter-token latency.
  Source: https://developers.openai.com/api/docs/changelog
