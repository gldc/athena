# AI/Tech Brief — June 26, 2026

### TL;DR
Google DeepMind unveiled computer use capabilities in Gemini 3.5 Flash, allowing the model to interact directly with computer interfaces. OpenAI's Codex Remote reaches general availability with ChatGPT mobile app control, while Anthropic introduces mandatory device verification for remote Claude sessions.

### Key Stories
* **[Introducing computer use in Gemini 3.5 Flash](https://blog.google/innovation-and-ai/models-and-research/gemini-models/introducing-computer-use-gemini-3-5-flash/)** — Google DeepMind launched new agentic capabilities for Gemini 3.5 Flash, enabling direct interaction with computer interfaces.
* **[Codex Remote reaches general availability](https://developers.openai.com/codex/changelog)** — OpenAI's Codex Remote is now GA, enabling control of connected Mac/Windows hosts directly from the ChatGPT mobile app.
* **[Enable Trusted Devices for Remote Control](https://support.claude.com/en/articles/12138966-release-notes)** — Anthropic now allows admins on Team and Enterprise plans to mandate device verification before viewing or steering Claude Code sessions remotely.
* **[Claude Code 2.1.193 updates auto-mode](https://code.claude.com/docs/en/changelog)** — Claude Code added an `autoMode.classifyAllShell` setting to route all Bash/PowerShell commands through the auto-mode classifier, improving security checks.
