# AI/Tech Brief — 2026-06-14

## TL;DR
- Anthropic briefly launched its new "Fable 5" Mythos-class model before abruptly suspending access amidst corporate restrictions.
- Google announced Gemini CLI will be replaced by Antigravity CLI for unpaid users next week, while DeepMind dropped Gemma 4 12B.
- OpenAI released tools directly targeting Claude users, offering easy migration from Claude Code to Codex.

## Key stories
- **Anthropic Fable 5 Launch and Suspension**: Anthropic released and quickly suspended access to "Fable 5", a new Mythos-class model, amid reports of corporate blocking. [Source](https://support.claude.com/en/articles/12138966-release-notes)
- **Gemini CLI Replaced by Antigravity CLI**: Google is officially sunsetting Gemini CLI for unpaid and Google One users, replacing it with Antigravity CLI on June 18. [Source](https://geminicli.com/docs/changelogs/)
- **OpenAI Codex Migration Tools**: OpenAI aggressively targeted Anthropic developers by introducing a direct migration flow from Claude Code to Codex. [Source](https://developers.openai.com/codex/changelog)
- **DeepMind Gemma 4 12B and Live Translate**: DeepMind shipped a new encoder-free multimodal Gemma 4 12B model and rolled out fluid real-time voice translation. [Source](https://deepmind.google/blog/)
- **OpenAI API Adds Web Search Images**: The OpenAI API's web search tool was upgraded to return image results like product photos and landmarks natively alongside text. [Source](https://developers.openai.com/api/docs/changelog)

## Quiet but interesting
- **Claude Code Localization**: Claude Code now automatically generates session titles and metadata in the language of the conversation. [Source](https://code.claude.com/docs/en/changelog)
- **Humanoid Volcano Summit**: A bipedal humanoid robot successfully summited a 20,000-foot volcano, a significant endurance milestone for autonomous navigation.
