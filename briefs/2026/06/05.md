# AI/Tech Brief — 2026-06-05

## TL;DR
OpenAI introduced moderation scores for its Responses API and shifted container sessions to per-minute billing. Gemini CLI v0.45.0 and Claude Code v2.1.165 shipped with architectural and reliability improvements. ByteByteGo published a comprehensive guide to understanding top AI agentic workflow patterns.

## Key Stories
- **OpenAI API Moderation and Billing Updates**: OpenAI added moderation scores to the Responses and Chat Completions APIs, and eligible container sessions are now billed per minute (5-minute minimum), lowering effective costs for short tasks.
  *Source: [https://developers.openai.com/api/docs/changelog](https://developers.openai.com/api/docs/changelog)*
- **Gemini CLI v0.45.0**: Shipped a major simplification of the `ContextManager` to improve robustness and exposed critical usage metadata in the Agent-to-Agent (A2A) protocol.
  *Source: [https://geminicli.com/docs/changelogs/](https://geminicli.com/docs/changelogs/)*
- **Claude Code v2.1.165**: A new point release for Claude Code brings bug fixes and reliability improvements to the CLI experience.
  *Source: [https://code.claude.com/docs/en/changelog](https://code.claude.com/docs/en/changelog)*
- **Top AI Agentic Workflow Patterns**: ByteByteGo's latest technical deep dive explains essential patterns—Reflection, Tool Use, ReAct, Planning, and Multi-Agent—for building effective AI problem-solvers.
  *Source: [https://blog.bytebytego.com/p/top-ai-agentic-workflow-patterns](https://blog.bytebytego.com/p/top-ai-agentic-workflow-patterns)*
- **Changing How We Develop Ladybird**: The team behind the independent Ladybird browser announced major shifts in their development and contribution processes.
  *Source: [https://ladybird.org/posts/changing-how-we-develop-ladybird/](https://ladybird.org/posts/changing-how-we-develop-ladybird/)*

## Quiet but interesting
- **databow (Rust CLI)**: A new command-line tool written in Rust allows developers to quickly query any database that has an ADBC driver.
  *Source: [https://columnar.tech/blog/introducing-databow//](https://columnar.tech/blog/introducing-databow//)*
- **Tracing GNSS Interference**: A fascinating pre-print traces a powerful GNSS (GPS) interference source over Europe, detailing real-world navigation disruptions.
  *Source: [https://arxiv.org/abs/2606.03673](https://arxiv.org/abs/2606.03673)*
