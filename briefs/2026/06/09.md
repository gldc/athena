# AI/Tech Brief: June 9, 2026

## TL;DR
Apple has unveiled a new AI architecture integrating Google's Gemini models, reshaping the mobile AI landscape. Key developer tools including Claude Code and OpenAI Codex CLI received major updates to streamline workflows and improve local context. Open-source innovation continues strongly with the release of OpenCV 5 and Xiaomi's high-speed 1-trillion parameter model.

## Key Stories
* **Apple Integrates Gemini:** Apple revealed a new AI architecture built entirely around Google Gemini models. [Source](https://www.macrumors.com/2026/06/08/apple-reveals-new-ai-architecture/)
* **Claude Code v2.1.169:** The new update adds a `--safe-mode` flag for troubleshooting, a `/cd` command to change directories without losing prompt cache, and UI/performance fixes. [Source](https://code.claude.com/docs/en/changelog)
* **Codex CLI Adds Desktop Handoff:** OpenAI released Codex CLI v0.138.0 featuring a `/app` command that passes CLI threads to Codex Desktop, while also exposing local image paths to the model. [Source](https://developers.openai.com/codex/changelog)
* **OpenCV 5 Released:** The most significant update in years to the computer vision library has been officially announced. [Source](https://opencv.org/opencv-5/)
* **Xiaomi's MiMo-v2.5-Pro-UltraSpeed:** A new 1-trillion parameter model capable of processing an incredible 1000 tokens per second. [Source](https://mimo.xiaomi.com/blog/mimo-tilert-1000tps)
* **Superhuman Overhaul:** Superhuman AI is undergoing its "biggest overhaul yet," which includes ChatGPT integrations allowing users to send emails directly from writing blocks. [Source](https://www.superhuman.ai/)

## Quiet but Interesting
* **Managing Token Spend:** A new piece explores routing strategies to better manage and control "out of control" token expenditure in production environments. [Source](https://blog.bytebytego.com/)
* **Microsoft Tools Compromised:** Hackers infiltrated Microsoft's open-source tools in an effort to steal passwords from AI developers. [Source](https://techcrunch.com/2026/06/08/microsofts-open-source-tools-were-hacked-to-steal-passwords-of-ai-developers/)

## Quiet Today
* Dario Amodei, Sam Altman, and Google DeepMind have not posted major updates in the past 24 hours.
