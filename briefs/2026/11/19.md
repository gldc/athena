- **Critical unauthenticated RCEs in NGINX's HTTP/2 code (patch now)**
  Five research teams independently found CVE-2026-123633 (use-after-free) and CVE-2026-123007 (send_window integer underflow), both CVSS 9.2 and exploitable without authentication when HTTP/2 is on — and NGINX fronts 225M+ websites. The underflow dates to NGINX 1.9.5 (2015). Fixed in 1.30.7 stable / 1.31.9 mainline; if you can't patch, disable HTTP/2. Wiz discovered the bugs with its AI scanning harness and validated impact with Gemini 4 Carbon and GPT-5.6 Sol. **Why it matters:** patch urgency aside, this is the loudest data point yet that AI is collapsing the cost of finding decade-old memory bugs — same pattern as yesterday's Java4Shell. (1,412 HN points, top story.)
  Source: https://www.wiz.io/blog/nginx-http2-rce-vulnerabilities · HN: https://news.ycombinator.com/item?id=50547374

- **Ruby2ßhell: pre-auth RCE on stock Rails via a one-byte heap overflow**
  Upcasing `ß` in Ruby's single-byte encodings writes two bytes but bounds-checks one, so 21 of them overflow the buffer; the bug has existed since Ruby 2.4.0 and is reachable in default Rails and classic Sinatra. Fixed in Ruby 4.0.10 / 3.4.13 / 3.3.14; GitLab 19.6.0 and GitHub Enterprise Server 3.22.5 ship affected Rubies, and the PoC drops in a week. Related Regexp/String case-conversion CVEs were patched the same day. **Why it matters:** if you run Rails, upgrade Ruby today — don't wait for the PoC. (179 HN points.)
  Source: https://verialabs.com/ruby2shell/ · HN: https://news.ycombinator.com/item?id=50556287 · Ruby advisory: https://www.ruby-lang.org/en/news/2026/11/18/multiple-vulnerabilities-in-regexp-and-string/
