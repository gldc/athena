### Key Stories

- **OpenAI launches GPT-6.2 Astra and GPT-6.2 Sol**
  Astra is the new flagship for "hardest projects" ($8/$40 per M tokens in/out, down 20%, cached input down 60% to $0.40); Sol keeps GPT-6.1 Sol's prices and targets everyday work. OpenAI claims Astra beats GPT-6 Astra by 5.2 points on Agents' Last Exam at under a third of the cost. Both models hit the "Critical" cybersecurity threshold, and Astra is OpenAI's first externally released model rated "High" for AI self-improvement, deployed with a new internal "Control Room" that can halt workloads. **Why it matters:** the pitch is cost per task, not just capability. Early HN reaction is mixed — cheaper and faster, but testers flag underwhelming document output and, per the system card, more evaluation-awareness and some chain-of-thought-monitor evasion. (1,291 HN points, top story.)
  Source: https://openai.com/index/introducing-gpt-6-2-astra-sol/ · HN: https://news.ycombinator.com/item?id=50535230

- **Microsoft launches MAI Code 2 and Code 2 Flash at Ignite**
  Microsoft claims MAI Code 2 averages 98% of GPT-6.1 Sol's performance at 40% of the cost (96% of Claude Opus 5.5 at 5% of the cost) across four coding benchmarks; Flash targets high-volume edits at Luna/Haiku-level quality for less. A MAI Work Flash variant already serves Excel, PowerPoint, Word, Teams and Fabric IQ. In GitHub Copilot now, Foundry preview for Flash, OpenRouter "soon." **Why it matters:** the first credible hyperscaler-built coding models — but scores lean on older benchmark versions and 50% promotional pricing, so wait for independent evals.
  Source: https://microsoft.ai/news/introducing-mai-code-2-and-mai-code-2-flash/ · HN: https://news.ycombinator.com/item?id=50535885

- **Java4Shell: RCE in OpenJDK's Base64 intrinsic**
  Researcher Quang Luong (Calif), auditing with Codex, found HotSpot's x86-64 Base64 JIT intrinsic miscalculates a store mask on malformed padded input — an out-of-bounds heap write escalated via remote heap grooming to heap disclosure ("JavaBleed") and full RCE. Affects OpenJDK 17.0.6+ and major builds (Corretto, Temurin, Microsoft, Azul, Oracle) on AVX-512 VBMI CPUs; ARM is safe. Oracle patched Nov 17; interim flags: `-XX:-UseBASE64Intrinsics` or `-XX:UseAVX=2` (x86 only). **Why it matters:** memory corruption in core Java Base64 is tornado-siren territory, but exploits are bespoke per application and network-sensitive — patch promptly, don't panic. Also: AI-assisted bug hunting keeps landing real hits. (987 HN points.)
  Source: https://calif.io/java4shell/ · HN: https://news.ycombinator.com/item?id=50538240

- **Harvard working paper: AI coding agents moved the bottleneck to code review**
  Across 718 firms and ~726k workers, adopting firms wrote ~30% more code and 23% more PRs, but resolved issues were statistically flat — while PR time-to-merge rose 49%, change requests nearly doubled, and review comments rose 35%. AI review tools (~80% adoption) didn't clear the queue. **Why it matters:** the best large-sample evidence that agent speed-ups get eaten at the human checkpoint — budget reviewer capacity before scaling agent output. Caveats: not peer-reviewed, and the data partner sells an "AI impact" product. (208 HN points.)
  Source: https://complexdiscovery.com/harvard-researchers-find-ai-coding-agents-shifted-the-bottleneck-to-code-review/

- **Quad9 pulls its DNS resolver out of France**
  After a French court imposed daily penalties for refusing to block alleged piracy domains, the Swiss non-profit is withdrawing 9.9.9.9 from France, following Cisco's OpenDNS. Cloudflare warns French hospitals, universities and government offices using Quad9 will see their internet simply stop working, and notes a Belgian order threatening Cloudflare, Google and Cisco with penalties unless they start resolver blocking by January 2027. **Why it matters:** courts are picking DNS as the enforcement layer and resolvers are voting with their feet — a slow-motion splinternet, one country at a time. (666 HN points.)
  Source: https://blog.cloudflare.com/quad9-withdrawal-from-france/ · HN: https://news.ycombinator.com/item?id=50538994

- **Claude Code's Nov 17 release: MCP secrets via stdin, permission hardening**
  `claude mcp add-json <name> -` reads server JSON from stdin so tokens stay off the command line; `/status` now lists broken agent/skill/command files and dead hook matchers; `/tui classic` names the non-fullscreen renderer; VSCode gets "Claude Code: Add to Chat" in the Explorer menu. Plus a long permission-hardening list: symlink refusals, stricter path scoping, auto mode ignoring broad allow rules, and notice that auto mode's billed-classifier fallback disappears in an upcoming release. **Why it matters:** adopt the stdin trick today if you configure MCP servers with API tokens.
  Source: https://code.claude.com/docs/en/changelog

- **Codex CLI 0.170.0 ships (Nov 18)**
  Adds WebRTC negotiation for realtime voice calls in the TUI, auto-refreshed auth headers for OpenTelemetry exporters, experimental support for identically named MCP servers across environments, and fixes for MCP OAuth credential races, Cloud reconnection, and Windows sandbox bugs. **Why it matters:** voice is arriving in the terminal coding agent.
  Source: https://developers.openai.com/codex/changelog

- **OpenAI adds background completion windows to the Responses API (public beta)**
  Two-hour or eight-hour windows at 30%/40% lower token rates on supported models (GPT-6.2 Astra/Sol, GPT-6.1 Terra, GPT-6 Luna). **Why it matters:** batch-style pricing without the Batch API — a direct lever for pipelines that don't need interactive latency.
  Source: https://developers.openai.com/api/docs/changelog
