# AI & Tech Brief — November 26, 2026

### TL;DR
- **The mathpocalypse is accelerating.** Scott Aaronson's "HOLY SHIT HOLY SHIT" post captures the mood: OpenAI's ω = 9/4 turns out to be a *matching lower bound*, a new OpenAI result pins the Fourier transform's linear-gate count below the 60-year-old FFT, and Google dropped a machine-generated, Lean-verified unconditional subexponential factoring algorithm.
- **1Password disclosed a breach**: an attacker entered through an employee's corporate GitHub account, pushed malicious code to backend services, and copied customer names and emails. Vault contents were never exposed.
- **Google will force AI agents onto its Workspace MCP servers** from February 2027 — and the Gmail MCP server can't send email. Separately, OpenAI quietly cut GPT-6.2 usage allowances.

### Key Stories

- **Scott Aaronson: "The magnitude of what's now happening"**
  Over dinner with colleagues, Aaronson watched three things land in one evening: OpenAI's and Anthropic's VP ≠ VNP proofs, the news that ω = 9/4 is a *lower bound* (matching the upper bound from OpenAI's October 6 "Mathocalypse" drop — the true exponent is rational, settled after 60 years), and a new OpenAI release proving the Fourier transform needs exactly N·(log N)^(1/2+o(1)) linear gates — beating the O(N log N) FFT that has stood since the 1960s, again with a matching lower bound. His kicker: Yupan Liu's AI-assisted QIP(2) = PSPACE proof, a result that would have been the complexity result of the year in 2025, now barely raises an eyebrow. "I now feel in my bones, for the first time ever, that a proof of P ≠ NP is not far." **Why it matters:** the field's most measured voice says the tempo change is real. 1,626 HN points.
  Source: https://scottaaronson.blog/?p=10379 · HN: https://news.ycombinator.com/item?id=50646108

- **Google Research: unconditional subexponential integer factorization, machine-generated**
  A paper in the google-research repo constructs an unconditional, zero-error Las Vegas algorithm factoring any integer in worst-case expected time L_N[1/3, O(1)] — the number-field-sieve regime, but with no unproven hypotheses — certified via AKS primality testing, with a complete Mathlib-only Lean 4 formalization promised alongside. The kicker: it was "entirely obtained by Cogentic," Google Research/DeepMind's agentic math-discovery framework running on Gemini 4, with "no human interaction other than the initial prompt." **Why it matters:** a flagship algorithms result with a machine-checked proof, produced end-to-end by an agent — exactly the pipeline Aaronson is describing.
  Source: https://github.com/google-research/google-research/tree/4a7bc8ab0bc770e71a259b7966c500496b99010a/cogentic_research_papers/integer_factorization · HN: https://news.ycombinator.com/item?id=50651627

- **Anthropic releases a much shorter Lean 4 proof of RH/GRH**
  The lsernau/grh-lean repo packages the Alpöge/Claude Riemann Hypothesis proof in two editions: a readable ~300k-line version and a ~76k-line compact one, proving RH and GRH for Dirichlet L-functions on Lean 4/Mathlib using only the standard axioms (propext, Classical.choice, Quot.sound). Caveats stated plainly: machine checks only — no mathematician has read it through, and there's no paper. **Why it matters:** proof compression is the readability bottleneck for machine-generated math; 4× shorter makes human audit at least conceivable.
  Source: https://github.com/lsernau/grh-lean · HN: https://news.ycombinator.com/item?id=50648050

- **1Password breach: customer names and emails copied; vaults untouched**
  On November 19 an attacker accessed an employee's corporate GitHub account, used it to push malicious code to backend services, and downloaded account records for a subset of users — names, emails, account identifiers, sign-in times, public keys, SRP parameters, and tokens from invitation/recovery emails. Private source code and the CI/CD system were also accessed. 1Password rotated all potentially exposed credentials and lengthened recovery codes from six digits to ten alphanumeric characters; vault contents and keys were never accessible to the attacker. **Why it matters:** password managers are the highest-value targets there are; the vault architecture held, but watch for phishing using the leaked emails. 1,474 HN points.
  Source: https://1password.com/blog/update-on-nov-2026-security-incident · HN: https://news.ycombinator.com/item?id=50644817

- **Google to AI agents: use our Workspace MCP servers — but the Gmail one can't send email**
  Google made its eight Workspace MCP servers generally available on Nov 24 and added an "AI Tools Addendum" to its API terms: from February 1, 2027, any tool that "is or is driven by an AI Agent" must reach Gmail, Drive, and Calendar through those servers; agents calling the REST APIs directly get throttled to Standard-tier quotas whatever they pay. The catch: the Gmail MCP server can search, read, and draft — but sending, replying, and forwarding "require partner access and aren't generally available." The addendum also bans training/evals/distillation on Workspace data and lets Google cap retention of embeddings and memory indexes at 30 days. **Why it matters:** the first major platform to wall off its APIs behind an agent-specific gateway — with the most-wanted capability withheld.
  Source: https://techstackups.com/articles/google-workspace-ai-agents-mcp/ · HN: https://news.ycombinator.com/item?id=50653477

- **Molotov cocktail thrown at Sam Altman's house**
  In a post updated overnight on his blog, Altman says someone threw a Molotov cocktail at his house at 3:45 am; it bounced off and no one was hurt. He connects the attack to "an incendiary article about me a few days ago" and to rising AI anxiety, and restates his positions at length: AI as moral obligation, democratization ("I do not think it is right that a few AI labs would make the most consequential decisions"), safety as a society-wide problem. **Why it matters:** rhetoric around AI leaders has turned physical; expect security and discourse fallout across the labs.
  Source: https://blog.samaltman.com/2279512

- **OpenAI cuts GPT-6.2 usage allowances**
  Users report emails that GPT-6.2 Astra now hits usage limits ~40% faster and Sol ~25% faster, with the initial notice so vague OpenAI had to send a clarification; separately, chat usage now subtracts from coding quotas. **Why it matters:** the generosity arms race between OpenAI and Anthropic is swinging back — if your workflow assumed bottomless Astra, recalibrate.
  HN discussion: https://news.ycombinator.com/item?id=50651117

- **nfs2root: 12-year-old pre-auth remote root in the Linux kernel's NFS server (CVE-2026-99362)**
  A latent remote-root bug in the kernel's NFS server, present for ~12 years, was disclosed on HN; the original writeup sits behind a bot wall, but the discussion confirms the CVE and notes kernel-side and XDP-firewall mitigations. **Why it matters:** check whether any host you run knfsd on is exposed — pre-auth remote root in the kernel is as bad as it gets.
  HN discussion: https://news.ycombinator.com/item?id=50647161
