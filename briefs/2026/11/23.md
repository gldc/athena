# AI & Tech Brief — November 23, 2026

### TL;DR
- **OpenAI published internal pretraining loss numbers and proposed cross-lab limits** — a long essay argues perplexity should be the shared industry metric for frontier progress, discloses OpenAI's own log-perplexity curve from GPT-3.5 to today, and floats "common limits" no lab should cross until monitoring catches up.
- **Z.ai shipped GLM-5.4, its first Loop Transformer flagship** — a 750B model that re-runs 28 layers for a second pass, claiming 2T–3T-class intelligence at far lower serving cost, with open weights promised after safety hardening.
- **It was a tooling weekend, not a model weekend** — Claude Code, Codex CLI, and the OpenAI API all shipped updates around Nov 19–20 (computer use betas, voice upgrades, GPT-6.2 defaults), while DeepMind, Gemini CLI, Altman, and Amodei stayed quiet.

### Key Stories

- **OpenAI: "Perplexity and Intelligence"**
  A first-person essay (top of HN overnight, 600+ points) arguing that pretraining perplexity — how well a base model predicts held-out text — is the one metric that has consistently predicted emergent capability jumps, and should become a shared cross-lab standard. It discloses OpenAI's internal log-perplexity figures: GPT-3.5 ~0.99, GPT-4 ~0.91, current models below 0.8, with a ~0.76 model reportedly producing "groundbreaking results" on open math problems. The author warns a similar capability avalanche in pretraining research itself is plausible "as soon as 2027," and proposes common perplexity-based limits labs would commit not to cross until alignment monitoring (e.g. a successor to chain-of-thought monitors) hits agreed milestones. **Why it matters:** a frontier lab volunteering a single comparable metric — and pre-committing to pauses — is a concrete step toward the "pacing" regime policy people have only theorized about.
  Source: https://openai.com/index/perplexity-and-intelligence/ · HN: https://news.ycombinator.com/item?id=50601525

- **Z.ai launches GLM-5.4, first flagship Loop Transformer**
  GLM-5.4 converts a pretrained 750B base into a looped architecture: 28 layers execute twice per token, with per-token gated updates, a hybrid shared/sliding-window KV cache, and reused sparse-attention indices so the extra pass costs a fraction of a full one. Z.ai claims intelligence comparable to 2T–3T parameter models, 200 tok/s off-peak throughput, shorter chains of thought (10–14% fewer thinking tokens on GPQA-Diamond and MMLU-Pro), and pushes "Generalized Coding" — code as the substrate for video generation, CAD, games, and 3D shaders. Open weights are promised "responsibly" after safety hardening; API access is listed as coming soon. Known limitation: occasional "marathon thinking" loops. **Why it matters:** recurrent depth is now validated at flagship scale — a real third scaling axis alongside parameters and data.
  Source: https://z.ai/blog/glm-5.4 · HN: https://news.ycombinator.com/item?id=50609685

- **Anthropic's Nov 20 drop: Claude Code enterprise sign-in, built-in charts, computer use for teams**
  Claude Code's latest release adds sign-in for organizations managed in Anthropic's Enterprise Admin Console (org settings and cloud gateway applied after `claude auth login`), a built-in "easel" mod that draws charts on request, stricter approval prompts for destructive `rm` targets, and VSCode `/fork` plus a workflows agent map. Same day, the Claude release notes added a refreshed Claude Mobile (iOS 26+) and expanded the computer-use beta — Claude viewing your screen and operating allowed desktop apps — to Team and Enterprise plans. **Why it matters:** Anthropic is productizing computer use for managed orgs before most enterprises have written a policy for it.
  Sources: https://code.claude.com/docs/en/changelog · https://support.claude.com/en/articles/12138966-release-notes

- **OpenAI API: GPT-Live-1.1 and cheaper background completions**
  Nov 19: GPT-Live-1.1 improves pronunciation, accent consistency, and transcription in multilingual voice sessions, with a new standby mode that pauses inference during silence in WebRTC sessions. Nov 17: GPT-6.2 Astra (hard reasoning/coding) and GPT-6.2 Sol (everyday coding/agent work) landed in the Responses API with a migration guide covering changed prefix-editing and `instructions` behavior, plus two- and eight-hour background completion windows at 30–40% lower token rates (Flex processing is being wound down for new models). **Why it matters:** background windows are a quiet price cut for batch-y agent workloads, and the 6.2 migration notes will bite anyone editing Responses API conversations.
  Source: https://developers.openai.com/api/docs/changelog

- **Codex CLI 0.171.0: GPT-6.2 Sol becomes the default, TUI workspace for everyone**
  The Nov 20 Codex CLI release adds GPT-6.2 Sol and Astra to the model catalog with Sol as the default, turns the TUI workspace on by default (searchable document previews, image previews, subagent transcripts beside the main conversation), adds configurable undo/redo in the composer, `codex exec --remote` to attach non-interactive sessions to an existing app server, and `/rc` + `/remote` for local remote-control pairing codes. **Why it matters:** Codex is converging on the "mission control for parallel agents" shape — the default-model switch also makes GPT-6.2 Sol the baseline most Codex users will actually run.
  Source: https://developers.openai.com/codex/changelog

- **XNU Linux: a full OS X GUI userspace on Linux**
  A GitHub project trending on HN (380+ points) that runs the classic Mac OS X (Aqua) GUI userspace on a Linux kernel — think Darling's inverse lineage, aimed at the Tiger/Leopard era. **Why it matters:** nostalgia aside, it's a serious compatibility-layer engineering artifact, and a reminder the desktop-compat scene (WINE, Darling, now this) keeps closing gaps emulators won't.
  Source: https://github.com/AFK-surf/xnulinux · HN: https://news.ycombinator.com/item?id=50607261

- **Docker rebrands for "the agentic era"**
  Docker's new brand — "The New Docker: Built to Run on Trust," new Moby and all — formally repositions the company around agent isolation and governance: the pitch is that containers isolate workloads, but agents are actors, so Docker is selling trusted supply chain, trusted runtime (Sandboxes), and AI governance on top. **Why it matters:** mostly marketing, but it marks the moment "we containerize the agent, not just the app" became a vendor's core identity.
  Source: https://www.docker.com/blog/meet-the-new-docker-built-to-run-on-trust/ · HN: https://news.ycombinator.com/item?id=50607194
