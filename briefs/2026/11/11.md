# AI & Tech Brief — November 11, 2026

### TL;DR
- **Google DeepMind formally verified the Signal protocol's production code** — its AlphaProof Code agents generated over six million lines of Lean proofs in four weeks, a first for a widely deployed cryptographic protocol.
- **Anthropic turned Claude into a collaborative workspace**: Whiteboards and Sheets launched in beta and Claude Data went GA, one day after Fable 5.2 became the Claude Code default.

### Key Stories

- **AlphaProof Code formally verifies Signal's cryptography**
  DeepMind researchers guided a multi-LLM agentic framework to prove key security properties of the actual compiled code behind the Signal protocol — forward secrecy and post-compromise protection — not just the design. Humans set the formal specs, Gemini Carbon agents did the proving (6M+ lines of Lean, all machine-checked), and flagged just 1% of the codebase for human review. The whole job took four weeks versus the years expert teams historically needed, and when two real, previously fixed bugs were reintroduced, the system produced machine-checked proofs that the buggy code was insecure. Verification artifacts are open-sourced. **Why it matters:** formal verification stops being boutique — this is the first time AI, or any method, has verified a widely deployed protocol implementation at this depth. (645 HN points.)
  Source: https://deepmind.google/blog/introducing-alphaproof-code/ · HN: https://news.ycombinator.com/item?id=50439193

- **Claude Whiteboards, Sheets, and Claude Data launch**
  Anthropic's biggest product drop since Cowork: Whiteboards (shared boards Claude builds from a brainstorm and can convert to docs/decks) and Sheets (prompt-generated spreadsheets with tabs, formulas, and tracked edits) are in beta on all paid plans, while Dashboards graduates to GA as Claude Data with certified metric queries, data stories, live sharing, and caching. Exports go to xlsx, Miro, Lucid, Airtable, and friends. **Why it matters:** Anthropic is building the work surface *around* the model — competing with Miro, Notion, and Microsoft 365, not just frontier labs. (242 HN points.)
  Source: https://claude.com/resources/articles/sheets-whiteboards-data · HN: https://news.ycombinator.com/item?id=50443716

- **VulnCheck's Glasswing audit: discovery isn't remediation**
  Seven months into Anthropic's vulnerability-hunting project, VulnCheck tracks 442 Anthropic-attributed CVEs (~0.5% of all CVEs this year), of which only two are known exploited in the wild. Anthropic's own ledger shows 37,966 findings versus 217 fixes — and the gap widened since September (+12,000 findings, +15 fixes). Duplicates (1,654) outnumber fixes nearly 8:1, and curl's maintainers rejected 19 of 34 OSS Scanner reports. **Why it matters:** the most concrete public scorecard on AI vuln-discovery claims — the findings scale, the fixes don't, and validation cost lands on maintainers. (410 HN points.)
  Source: https://www.vulncheck.com/blog/anthropic-glasswing-november-update · HN: https://news.ycombinator.com/item?id=50447074

- **Apple's "Harbor" app leaks: your Mac as a private AI inference server**
  A leaker found evidence of an Apple app that runs open-weight models locally on Apple silicon and pools unified memory across multiple Macs over Thunderbolt 5 — auto-detecting cluster setup, in-app model downloads, no cloud. It's in private preview under Apple's Claris brand. **Why it matters:** Apple's clearest move yet to own the local-inference niche, pitching Mac Studio clusters as private AI infrastructure. (296 HN points.)
  Source: https://9to5mac.com/2026/11/10/apple-has-new-mac-app-coming-to-make-running-local-ai-models-easy/ · HN: https://news.ycombinator.com/item?id=50446520

- **GitHub ported Copilot's runtime from TypeScript to Rust — using Copilot**
  ByteByteGo's detailed write-up of GitHub's migration: ~430K lines of production TypeScript ported by essentially one developer directing agent fleets, in months instead of the years a team would have needed. The numbers are worth quoting: $120K in token costs across ~136B tokens (mostly cached input), 15 child sessions parallelized on a single 30K-line file, client lifecycle time cut 5.25s → 292ms (~18x), and peak memory down 1,383MB → 126MB in a 10-client test. The honest part is the regression list: integers silently becoming decimals, cancelled operations not stopping work, frozen UIs from Rust blocking Node's main thread. **Why it matters:** the best costed public account yet of AI-driven large-scale migration — including what it actually breaks.
  Source: https://blog.bytebytego.com/p/how-github-used-ai-to-port-copilot

- **Val Town is winding down**
  The serverless JavaScript platform is shutting down after four years, conceding it couldn't compete in cloud compute. Billing paused today (existing subs run free), read-only mode December 10, full shutdown January 10, 2027, code open-sourced February 1 — with migration guides to Cloudflare, Vercel, Netlify, and Render, and a nod that "today's LLMs are great at these types of migrations." **Why it matters:** a beloved dev tool folds; also a sign of the times that the farewell note recommends LLM-assisted migration as the escape hatch. (393 HN points.)
  Source: https://blog.val.town/winding-down · HN: https://news.ycombinator.com/item?id=50443427
