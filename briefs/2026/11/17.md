### Key Stories

- **Optimizely compromise serves malware on Zoom, GitLab, BBC and 175 other sites**
  On Nov 16 an attacker wrote malicious "Project JavaScript" into Optimizely Web customer projects, so trusted Optimizely CDN snippets served a multi-purpose kit: swapping crypto wallet addresses (verified thefts of ~$7,040), skimming payment cards from native forms, stealing cookies and screenshots, and hitting iPhones on iOS ≤18.6 with the Coruna and DarkSword exploit kits. 188 of 1,611 scanned snippets were infected; mass cleanup finished by ~23:11 UTC and the C2 domains are being taken down. **Why it matters:** your site can serve malware without being breached — third-party JS trust is the attack surface, and a strict `script-src` CSP was the only thing that protected the 15% of sites that blocked the payload. (397 HN points.)
  Source: https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/ · HN: https://news.ycombinator.com/item?id=50524767

- **Windows 11 records which coding agents and dev tools you use**
  Reverse engineering of `MissionControlAggregator.dll` (feature flag `CLICodingAgentUsage`, already enabled) shows Windows watching for codex.exe, claude.exe, copilot.exe, cursor.exe and antigravity.exe — plus python, gcc, node, code.exe and friends — saving a bitmap locally and reporting it over ETW. It's classed as "optional" diagnostic data, on by default in the clean US Windows 11 install tested, and the author found the agent-usage event queued in DiagTrack's upload store. No prompts or code are collected, only which tools ran. **Why it matters:** cohort-level telemetry of the AI-coding market is being built into the OS; disable it at Settings → Privacy & security → Diagnostics & feedback → "Send optional diagnostic data". (634 HN points.)
  Source: https://xusheng.dev/posts/windows-coding-agent-telemetry/ · HN: https://news.ycombinator.com/item?id=50524736

- **JPMorgan Chase software bug disrupts online banking, delays Zelle**
  A "temporary issue related to a software bug in an on-premise hardware system" at Chase left thousands of customers locked out of accounts Monday and delayed Zelle transfers at other banks transacting with Chase; BofA, Citigroup and U.S. Bank all said their own systems were fine. Chase says the incident is not cyber-related and expected services restored by end of day. It lands days after Thursday's Microsoft outage and Friday's FAA ground stop. **Why it matters:** three headline US infrastructure failures in as many business days — and "not a cyberattack" bugs now have cyberattack-scale blast radius. (786 HN points.)
  Source: https://apnews.com/article/bank-outage-chase-wells-fargo-truist-50fee2693c22f597fa6ca51a97ef2cda · HN: https://news.ycombinator.com/item?id=50521045

- **Claude Code's Nov 16 release: auto mode becomes the default**
  Sessions with no mode set now start in auto mode instead of Manual, and orgs on the Claude Code + Cowork HIPAA configuration get server-side action classification on direct API connections. The Bash sandbox tightens further: no more writes to sensitive home folders by default, state kept across more of a session, and hooks that "block" now hold in more cases. Code Mode also now works alongside agent teams. **Why it matters:** the largest coding-agent install base just got more autonomous by default and more sandboxed at once — expect a wave of "why did this command get refused?" reports today.
  Source: https://code.claude.com/docs/en/changelog

- **How the Claude Code team verifies agent-written code**
  Roughly 90% of Claude Code's own code is written and reviewed by Claude; this post is the verification playbook. A separate grader scoring work against a rubric buys up to +10 task-success points; E2E tests beat unit tests because they're hard to fool; property tests catch edge cases the writing agent is biased against; differential tests gate migrations. Checks live on a branch the change can't modify, three failed fix rounds pull in a human, and every commit is stamped with how it was verified. **Why it matters:** the most concrete published account of running dozens of parallel coding agents safely — worth stealing for your own repos. (HN front page overnight.)
  Source: https://claude.dev/blog/how-the-claude-code-team-thinks-about-verification/ · HN: https://news.ycombinator.com/item?id=50529612

- **OpenCode Browse lets agents drive your real browser**
  An MCP server plus a Chromium extension that gives any MCP client (OpenCode, Claude Code, Cursor, Codex, Zed) your actual browser: your tabs, logins, and extensions. Agents work in collapsed background tab groups — reading, clicking, typing, screenshotting, recording — and hand the tab back to you for logins, 2FA, or payments, then continue when you click Continue. Site allowlists keep them bounded. **Why it matters:** "agent uses my logged-in browser" was everyone's Playwright-profile hack; this productizes it with human handoff as a first-class feature. (282 HN points.)
  Source: https://opencode.ai/product/browse · HN: https://news.ycombinator.com/item?id=50523459

- **OpenAI offers a free CSAM image classifier to approved orgs**
  Yesterday's API changelog adds `omni-moderation-csam-latest` to the Moderations endpoint: separate signals for potential CSAM and potential AI-generated CSAM, at no cost to approved organizations, to help prioritize images for human review. **Why it matters:** a rare unambiguous safety freebie — and the "AI-generated CSAM" signal formalizes a moderation category that barely existed two years ago.
  Source: https://developers.openai.com/api/docs/changelog

- **Mem, an early AI-native notes app, is shutting down**
  Notes go read-only December 18, 2026; the service closes January 15, 2027. Billing is paused and there's a migration guide covering Apple Notes, Notion, Obsidian and others. Mem shipped embedding-based "Similar Mems" in 2022 and a proactive agent in 2026 — early to ideas the platforms later absorbed. **Why it matters:** the AI-notes category is consolidating into ChatGPT, Claude and Notion; if you have anything in Mem, export it this month.
  Source: https://get.mem.ai/blog/mem-is-shutting-down
