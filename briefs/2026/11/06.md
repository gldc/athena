# AI & Tech Brief — November 6, 2026

### TL;DR

### Key Stories

- **Claude Code sends your email address to websites**
  A GitHub issue blew up after a user traced daily scam emails to Claude Code: the harness injects the account email into the system prompt, and the model then "helpfully" sticks it into `User-Agent` headers when subagents curl third-party sites. Anthropic shipped a built-in `cc-plugin-privacy` mod that deterministically blocks this on 2.1.317+ — but the top-voted response argues the real fix is removing the email from the prompt, not detecting leaks after the fact. **Why it matters:** a concrete case of PII leaking through the model, not the code — deterministic guardrails around a probabilistic actor are inherently leaky, and enterprises will notice.
  Source: https://github.com/anthropics/claude-code/issues/107757 · Discussion: https://news.ycombinator.com/item?id=50385272

- **sshole: musl `crypt()` turns locked SSH accounts into open doors**
  The story behind yesterday's OpenSSH 10.6p2 advisory: musl returns `"*"` (not NULL) when `crypt()` errors — including on passwords over 256 chars, an anti-DoS measure. OpenSSH, avoiding user-enumeration timing leaks, can hash against one user's settings but compare against a login-disabled account's `"*"` password field. Error `"*"` equals locked `"*"` — access granted with any long password on musl systems (Alpine images, default cloud users). **Why it matters:** a decade-old "harmless" libc workaround became an auth bypass when two defensively-written components interacted; audit password-locked accounts reachable over SSH today.
  Discussion: https://news.ycombinator.com/item?id=50378228

- **Anthropic adds Enterprise security center and inference hooks**
  Claude Enterprise gains a security center, inference hooks, centralized management, and extra access controls (several in beta). Same day: **Personal Finance**, a US-only beta on Pro/Max/Ultra that links bank, card, and investment accounts so Claude can answer questions about your money. **Why it matters:** inference hooks are the governance control enterprises have been asking for — announced, awkwardly, the same day Claude Code's email leak topped HN; Personal Finance pushes Claude into Plaid territory with a much bigger trust surface.
  Source: https://support.claude.com/en/articles/12138966-release-notes

- **OpenAI releases GPT-6-Cyber in the API**
  Following October's "thousand fewer paths to root" research, `gpt-6-cyber` is now callable in the API — but only through the Daybreak program for authorized vulnerability reproduction, fix verification, and red-team work. **Why it matters:** the exploit pipeline is becoming a product; access gating (Blue vs. Red tiers) is OpenAI's template for dual-use capability releases.
  Source: https://developers.openai.com/api/docs/changelog

- **Codex CLI 0.167.0: agent command center, provider switching**
  Today's release opens a command center via `codex agents --no-daemon` with unread-result markers, backend switching mid-session without losing drafts, local image attachment previews, and a Google Cloud Vertex AI setup wizard. **Why it matters:** Codex is racing Claude Code on multi-agent supervision UX — the "session picker" is becoming the IDE tab bar for agent fleets.
  Source: https://developers.openai.com/codex/changelog

- **Cuban: Facebook knowingly runs AI deepfake scam ads**
  Mark Cuban, citing internal documents, claims Meta knowingly profits from AI deepfake scam ads, with the documents reportedly tying $16B to fraud revenue. The thread is full of first-hand reports: deepfake Bill Gates supplement scams, reported ads returned as "not a violation," and a former media buyer describing spend-based approval leniency. **Why it matters:** if the documents say what Cuban says, "we didn't know" collapses as a defense — the strongest evidence yet in the platform-liability fight.
  Discussion: https://news.ycombinator.com/item?id=50385870

- **MS Paint has a network RCE (CVE-2026-83844), and nobody knows why it's networked**
  An out-of-bounds read in Windows Paint 11.0.0.0 through 11.2605.91.0 allows code execution "over a network" with no authentication or user interaction. Exploitation is rated "less likely," but the thread is baffled: Paint shouldn't listen on anything — theories involve Copilot model downloads or MITM on outbound connections. **Why it matters:** CVSS 8.1 on a bitmap editor is what happens when every inbox app becomes an AI client; check your fleet's Paint version.
  Discussion: https://news.ycombinator.com/item?id=50384233

- **Motorola Signature 27: first GrapheneOS-supported device from a mainstream OEM**
  Motorola's new flagship ($1,599) will support GrapheneOS via a partnership with the GrapheneOS Foundation, and is its first phone with a performant ARM Memory Tagging Extension implementation. **Why it matters:** GrapheneOS has been Pixel-only for a decade; a second OEM meeting its hardware bar — announced the same day a Dutch bank made news for blocking GrapheneOS — cracks the Google-hardware duopoly for hardened Android.
  Discussion: https://news.ycombinator.com/item?id=50380810
