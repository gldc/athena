# AI & Tech Brief — November 8, 2026

### TL;DR
- **Claude Code's "Don't Ask Again" is leaking secrets into public repos**: researchers found 1,122 public GitHub files where saved permission rules sit alongside exposed passwords — the weekend's biggest Hacker News thread, with Anthropic staff defending the design in the comments.

### Key Stories

- **Claude Code "Don't Ask Again" permissions expose secrets in 1,122 public GitHub files**
  Apiiro research (top HN thread, ~430 points) found developers committing `.claude/settings.local.json` permission files that bake in broad approvals — per figures quoted in the thread, 5% allow any shell command outright and another 43% allow interpreter wildcards like `Bash(python:*)` — in repos that also expose passwords. Boris from the Claude Code team responded: the file is meant to stay local and is auto-gitignored when Claude creates it, so the checked-in copies were manually created; he pointed to auto mode and GitHub secret scanning as the real mitigations. **Why it matters:** saved-approval files are becoming a credential-leak vector unique to agentic tooling; expect scanners and harnesses to start treating them like `.env`. (The Apiiro post itself sits behind a bot wall; the HN thread carries the substance plus Anthropic's response.)
  Discussion: https://news.ycombinator.com/item?id=50407882

- **The end of Microsoft Research's AI Frontiers group**
  John Langford's post-mortem: after ChatGPT, lone-researcher projects couldn't move fast enough, so ~50 people organized AI Frontiers inside MSR — the group behind the AutoGen orchestration framework and the Fara computer-use agent, plus fundamental work like the Next Latent objective and a shared MSR-wide monorepo with a proven edge-scale pretraining codebase. In early September the group was reorged into Microsoft AI. **Why it matters:** a candid first-person account of a corporate research org concluding that agent-era research needs coordination and compute more than lone cleverness — and of that org being absorbed anyway.
  Source: https://hunch.net/?p=13764006

- **GitHub's new pull request Overview page enters public preview**
  Opt-in preview rolling out through the weekend: merge readiness, blocking checks, and next actions move into a compact summary at the top, and comments can be filtered to unresolved threads and sorted newest-first. **Why it matters:** GitHub is explicitly rethinking the PR page because agent-generated volume is overwhelming review; the HN thread (~150 points) splits between "finally" and "fix stability first."
  Source: https://github.blog/changelog/2026-11-05-new-pull-request-overview-page-in-public-preview/ · Discussion: https://news.ycombinator.com/item?id=50408931

- **Xiaomi humanoids work a full 8-hour factory shift**
  Footage from Xiaomi's EV plant shows humanoid robots sorting car parts from bins into storage racks for an entire shift — autonomously, fixing their own mistakes, covering the workstation's full day of production, per the company. The same robotics roundup: MIT built a system that lets robots catch and correct faulty visual memories (resolving ~92% of object ambiguities in testing), and Waymo confirmed it will end its Uber exclusive in Austin and Atlanta, taking bookings in its own app from January 2028. **Why it matters:** a full unsupervised shift is the bar factory robotics has to cross for the deployment math to work — with the caveat that the footage is the vendor's own.
  Source: https://www.superhuman.ai/p/robotics-special-xiaomi-s-humanoid-robots-clock-in-for-a-full-8-hour-factory-shift

- **Every Mac ships a personal knowledge graph — now you can read yours**
  An 8rank.ai deep dive (~750 HN points) documents the pair of daemons in every macOS since version 13 that build a graph of who you know, how those people are related, how you communicate, and where you go — and ships a tool to peek into your own graph. **Why it matters:** the on-device intelligence Apple pitches as private is a richer dossier than most users expect; this makes it visible.
  Source: https://8rank.ai/
